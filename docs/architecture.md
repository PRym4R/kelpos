# Архитектура (v2)

**Принцип: взять Linux, вырезать 95% конфигурацией, оставить только нужное,**
сверху — свой минимальный, suckless-слой. Это даёт нативную работу всех
компонентов из списка (pipewire, dwm, iwd…) и железный минимум мусора.

```
┌──────────────────────────────────────────────────────────────┐
│ GUI: X11 (Xorg) + dwm + st + dmenu                           │
│ приложения: PCManFM, nsxiv · звук: pipewire + wireplumber    │
├──────────────────────────────────────────────────────────────┤
│ userland: runit · shell · doas · glibc (статик)  [наше]      │
├──────────────────────────────────────────────────────────────┤
│ Linux 6.18 — обстрижен Kconfig:                              │
│  x86_64 · ext4 · DRM/KMS · сеть(IP/802.11)/bt · ALSA         │
│  binfmt_misc · devtmpfs · serial · virtio(QEMU)              │
│  ✗ старые ЦПУ ✗ серверное ✗ вирт-гость ✗ лишние ФС           │
├──────────────────────────────────────────────────────────────┤
│ Limine (UEFI) → bzImage                                      │
└──────────────────────────────────────────────────────────────┘
```

## Почему v2 (пивот)

v1: своё ядро + Linux в клетке. Правда: pipewire/dwm/iwd/PCManFM —
это Linux-userland, они физически живут на Linux API; «клетка» отодвигала
их на годы. Обстриженный Linux даёт тоже самое сегодня, а «чистоту» несёт
в конфиге и поверхностном слое.

## keep-list (linux/configs/enable.list)

Единое место правды. База `allnoconfig` → включаем только список →
`olddefconfig` достраивает зависимости. 95% кода просто не собирается.

Открыть фичу = добавить символ. Driver-мусор не подтянется сам по себе.

## binfmt_misc и .exe

Ядро НЕ «понимает» PE: binfmt_misc маршрутизирует неизвестные форматы на
хэндлер. Для .exe хэндлер = Wine (через фst binfmt=wine). Отдельный нативный
PE-загрузчик — мечта на финальную фазу, изолированная подсистема.

## Безопасность (OpenBSD-дух)

- doas, не sudo
- devtmpfs без udev, статичные бинарники, без namespaces-каши
- меньше фич в ядре = меньше поверхность атаки; всё остальное — песочница уже
  в userland (pledge/unveil-style тулинг — см. TODO)
- (QEMU-виртуализацию в госте выключили; virtio — только для разработки)
